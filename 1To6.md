### **Exercise 1: Boosting Rank via New Pages**
**Analysis:** In the original four-page web (Figure 2.1), the importance score $x_k$ is derived from backlinks[cite: 44, 45]. If the owners of page 3 create a new page 5 that links to page 3, and page 3 links back to page 5:
* **Vote Redistribution:** Page 3 originally cast its entire vote for page 1 ($n_3 = 1$)[cite: 82]. Now, it must divide its vote between page 1 and page 5 ($n_3 = 2$), giving each $x_3/2$[cite: 61].
* **New Backlink:** Page 3 now receives a new backlink from page 5, which contributes $x_5/1$ to its score[cite: 64].
* **Conclusion:** This "link farm" increases the score of page 3 because it receives the full weight of page 5's importance, though the exact ranking relative to page 1 depends on the full system's eigenvector calculation[cite: 86, 138].

### **Exercise 2: Multi-Subweb Rankings**
**Analysis:** When a web consists of $r$ disconnected subwebs (like $W_1$ and $W_2$ in Figure 2.2), the link matrix $A$ assumes a **block diagonal structure**[cite: 116, 120, 121].
* **Linear Independence:** Each block $A_i$ is a column-stochastic matrix in its own right and possesses an eigenvector with eigenvalue 1[cite: 122, 123].
* **Dimension:** We can construct $r$ linearly independent eigenvectors by padding the eigenvector of each subweb with zeros for the other components[cite: 123, 125, 126].
* **Conclusion:** Therefore, the dimension of the eigenspace $V_1(A)$ is at least $r$[cite: 116, 130].

### **Exercise 3: Connecting Subwebs**
**Analysis:** In Figure 2.2, the web consists of two disconnected components, meaning $\dim(V_1(A)) \ge 2$[cite: 116, 119].
* **Impact of Link:** Adding a link from page 5 to page 1 connects the subweb $W_2$ to $W_1$[cite: 141].
* **Conclusion:** If this link makes the entire graph "strongly connected" (meaning you can get from any page to any other page), then $\dim(V_1(A))$ will be reduced to **1**, yielding a unique ranking[cite: 108, 116].

### **Exercise 4: Dangling Nodes and Perron Eigenvectors**
**Analysis:** If we remove the link from page 3 to page 1 in the Figure 2.1 web, page 3 becomes a **dangling node**[cite: 143].
* **Matrix Property:** The resulting link matrix $A$ will contain a column of all zeros, making it **column-substochastic**[cite: 133, 134].
* **Eigenvalue:** In this case, 1 is no longer guaranteed to be an eigenvalue[cite: 135].
* **Ranking:** To rank the pages, we must find the largest positive eigenvalue $\lambda \le 1$ and its corresponding **Perron eigenvector**[cite: 136, 144].

### **Exercise 5: Pages with No Backlinks**
**Analysis:** The importance score of a page $k$ is defined by the formula: $x_{k}=\sum_{j\in L_{k}}\frac{x_{j}}{n_{j}}$[cite: 64].
* **Proof:** If a page has no backlinks, the set $L_k$ (the set of pages linking to $k$) is empty[cite: 62, 147].
* **Result:** The sum over an empty set is 0. Thus, $x_k = 0$[cite: 147].

---

### **Exercise 6: Invariance of Indexing**
**Analysis:** The manner in which pages are indexed (labeled 1 to $n$) has no effect on the final importance score[cite: 148].
* **Permutation Matrix:** Relabeling pages is equivalent to applying a permutation matrix $P$ such that the new link matrix $\overline{A} = PAP$[cite: 151, 152].
* **Eigenvector Consistency:** If $x$ is an eigenvector for $A$ ($Ax = \lambda x$), then $v = Px$ is an eigenvector for $\overline{A}$ with the same eigenvalue $\lambda$[cite: 155].
* **Conclusion:** This proves that swapping or permuting the page indices simply reorders the components of the importance vector without changing the actual scores assigned to the pages[cite: 156].
